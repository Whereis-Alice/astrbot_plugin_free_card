# 名片管理面板

在 AstrBot 的插件管理中选择 **随心名片 → 视图 → 名片管理**。面板使用 AstrBot 自带的登录和插件页面接口，无需配置新端口、额外账户或 API Key。若没有视图入口，请更新 AstrBot；不支持视图的核心仍可使用改名工具。

## 概览与群管理

概览展示最近回读的名片、过去 24 小时确认的变化、最近 7 天趋势和当前配置。日期按照浏览器本地时间显示；统计范围受最近 1000 条记录的保留上限影响。

群收到一次实际消息后，插件会记录对应的连接、机器人账号与群号。管理操作只作用于选中的机器人自己的名片。同一群接入多个机器人时分别管理，不会误用其他机器人的账号。

群名称在点击“回读 QQ”时读取；没有读到名称时显示群号。界面每 30 秒更新本地状态，不会因此轮询所有 QQ 群。

| 操作 | 效果 |
| --- | --- |
| 回读 QQ | 查询所选机器人的当前名片，并尽可能读取群名称；不写入改动记录 |
| 手动改名 | 提交你填写的名字，遵守命名规则、最短间隔、失败冷却和小世界串门恢复规则 |
| 暂停提醒 | 暂停此群之后的日常提醒；已经开始的请求、模型主动调用工具和串门状态仍可继续 |
| 恢复提醒 | 恢复按配置间隔提供日常提醒 |
| 下次聊天提醒 | 在下一次合格模型请求中提醒；仍遵守工具权限、冷却和串门暂停，不会额外启动模型 |

“下次聊天提醒”也可在定期提醒关闭时安排一次提醒。仅准备后被取消的请求不会消耗这次安排，模型实际开始时才消耗。已暂停的群需先恢复提醒。

## 改动记录

记录包含时间、连接、机器人账号、群号、来源、修改前名片、请求名片、QQ 回读名片和结果。修改前没有读到名片时显示“之前未读取”，不会推测旧名字。

来源分为定期提醒、模型工具、管理面板、小世界串门和归家恢复。模型工具只表示本轮未附定期提醒，既可能是 bot 主动调用，也可能是用户要求调用，插件不会擅自判定。

| 结果 | 含义 |
| --- | --- |
| QQ 已确认 | QQ 回读结果与请求名片一致 |
| 未变化 | 回读已经是所选内容，没有重复写入 |
| 尚未确认 | 接口接受了提交，但回读暂不可用；不算确认成功 |
| 失败 | 提交失败，或回读仍为其他名片；遵守 5 分钟失败冷却 |
| 待归家恢复 | 串门期间保存了新的日常名字，当前临时名片保持，归家后恢复 |
| 提交中断 | 提交过程中被重载或取消，结果还未确认，保留恢复记录 |

重复的串门状态检查不会不断生成相同记录。工具没有被调用、输入校验失败或因冷却未提交时，可在后台 `[随心名片]` 日志查看原因，不会捏造成名片变化。

可按群、来源、结果、日期和文字筛选。CSV 与 JSON 导出覆盖当前筛选条件下的全部保留记录，不限于当前页；CSV 时间使用带时区的 UTC 时间，文字会防止被表格软件当作公式执行。

记录和群暂停设置保存在插件的 AstrBot KV 数据中，最多保留最近 1000 条。升级前的历史不会补造；重载保留这些记录，但提醒和冷却仍重新计时。

## 配置与主题

保存配置后立即生效，无需重载。已有 QQ 名片要等下一次成功改名后才变化。基础名字留空时，工具允许 bot 重写完整名片，不必保留角色名；这并不禁止 bot 自愿选择自己的名字。

修改提醒文字时，模型仍沿用本轮已有聊天、人格与记忆；面板不会额外注入当前名片或小世界处境。提醒内容不会发送给群友。

四套主题：

- **月白**：暖白与淡紫，清透轻盈。
- **夜航**：深蓝与星光，安静专注。
- **玫瑰**：柔粉与酒红，温柔浪漫。
- **森屿**：米白与苔绿，自然舒展。

主题偏好保存在当前浏览器，仅改变管理面板外观。不同设备可各自选择，页面也支持窄屏手机布局。
