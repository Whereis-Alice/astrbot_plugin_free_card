# 常见问题

## bot 没有改名

确认当前人格启用了 `set_free_group_card`，模型支持工具调用，且聊天发生在 OneBot 接入的 QQ 群。插件只在已有模型请求中提醒，不会额外调用模型或在安静的群里启动任务。

提醒让 bot 自己决定是否换名，不保证每次都改。希望保留角色名时，可以把“保持角色名，其他部分自由发挥”写进提醒或人格。

## 改名失败

查看同一时间的 AstrBot 与 OneBot 客户端日志。`1200` 是客户端执行失败的通用返回，不能仅凭它判断权限问题。确认机器人在线、可以修改自己的名片，并检查内容、长度和频率限制。

llbot + PMHQ 环境曾出现重启后机器人内部 UID 错配，导致底层 QQ 返回 `1013`。这种情况需要在客户端核对自身身份；插件无法替客户端修正登录信息。给机器人管理员权限不能解决身份错配。

每次工具调用最多提交一次写入，随后回读；不做连续写入重试。已生效但返回错误的请求，可通过回读确认成功。接口接受却无法回读时，仅报告未确认。

## 用哪个插件

随心名片是独立插件，工具名为 `set_free_group_card`，参数只有 `card`。由完整文本直接改名，没有基础名字、模板、日程、系统指标、随机候选池、临时后缀或定时任务。与原灵动名片一起使用时，应关闭其中一个插件的改名功能，避免互相覆盖。

## 验证范围

使用 AstrBot SDK 检查工具注册和提醒 Hook，通过模拟 OneBot 响应验证修改、超时、回读、并发及失败冷却，并运行 Linux CI。此独立版本尚未连接真实 QQ 账号实测。QQ 实际权限与限制以所用客户端和账号为准。
