# 常见问题

## bot 没有改名

确认当前人格启用了 `set_free_group_card`，模型支持工具调用，且聊天发生在 OneBot 接入的 QQ 群。插件只在已有模型请求中提醒，不会额外调用模型或在安静的群里启动任务。

提醒让 bot 自己决定是否换名，不保证每次都改。希望固定角色名时，填写可选的“基础名字”，插件会在实际提交时保留它。留空时，bot 可自由修改完整名片。

## 基础名字与后缀

配置基础名字后，工具参数 `card` 表示后缀；留空配置时，`card` 表示完整名片。工具说明与提醒会告诉 bot 当前模式。即使关闭定期提醒，固定基础名字的规则仍然生效。

基础名字和后缀以一个空格连接，每次用新后缀替换旧后缀。工具传入空字符串可清除后缀，但只在配置了基础名字时允许。bot 若仍传入“基础名字 后缀”，插件会去掉开头重复的基础名字，避免拼接两遍。最终总长度超限时拒绝修改，原名片保留。

## 改名失败

查看同一时间的 AstrBot 与 OneBot 客户端日志。`1200` 是客户端执行失败的通用返回，不能仅凭它判断权限问题。确认机器人在线、可以修改自己的名片，并检查内容、长度和频率限制。

llbot + PMHQ 环境曾出现重启后机器人内部 UID 错配，导致底层 QQ 返回 `1013`。这种情况需要在客户端核对自身身份；插件无法替客户端修正登录信息。给机器人管理员权限不能解决身份错配。

每次工具调用最多提交一次写入，随后回读；不做连续写入重试。已生效但返回错误的请求，可通过回读确认成功。接口接受却无法回读时，仅报告未确认。

## 用哪个插件

随心名片是独立插件，工具名为 `set_free_group_card`，参数只有 `card`。可自由修改完整名片，也可填写基础名字后只修改后缀。没有模板、日程、系统指标、随机候选池、后缀有效期或定时任务。与原灵动名片一起使用时，应关闭其中一个插件的改名功能，避免互相覆盖。

## 验证范围

使用 AstrBot SDK 检查工具注册和提醒 Hook，通过模拟 OneBot 响应验证修改、超时、回读、并发及失败冷却。本地运行回归测试，不触发 CI；真实部署按 OneBot 回读确认结果。QQ 实际权限与限制以所用客户端和账号为准。
