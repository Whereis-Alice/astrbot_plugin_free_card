# 随心名片

让 bot 根据聊天、心情和人格，自由决定自己的 QQ 群名片。

插件定期在模型准备回复时给出提醒，让 bot 先使用工具自主改名，再继续回复。你也可以在管理面板调整配置、管理群名片和查看最近的变化。只修改机器人自己的群名片。

## 安装

1. 在 AstrBot 中通过 **OneBot v11 / aiocqhttp** 接入 QQ，如 LLOneBot、llbot 或 SnowLuma。
2. 在插件管理中从链接安装：

   ```text
   https://github.com/Whereis-Alice/astrbot_plugin_free_card
   ```

3. 在当前人格的工具设置中启用 **`set_free_group_card`**，使用支持工具调用的模型。
4. 关闭其他自动改名插件，再在群里与 bot 聊天。

**QQ 官方机器人不开放群名片修改接口，无法使用此功能。**

## 怎么用

默认每隔 30 分钟，在下一次群聊模型请求中提醒 bot 自主改名。首次群聊会立即提醒，群里没人聊天时不会自行触发。

间隔从**模型实际开始处理上次提醒**或**上次成功改名**起算，以较晚的一次为准。例如设为 10 分钟、15:00 改名成功，15:10 后的下一次合格群聊请求才会提醒；并非到点立即改名。准备后取消、没有运行的请求不占用间隔。

提醒出现时，模型先调用改名工具，再继续原来的回复；0 分钟关闭定期提醒，工具仍可使用。

你也可以直接对它说：

> 按你现在的心情，给自己换个群名片。

> 把你的群名片改成“月亮打了个盹”。

工具只接收一个参数 `card`。**基础名字留空**时，bot 自由决定完整名片。可以是短句、意象或绰号，不限于“角色名＋状态”。插件不会自动添加角色名前缀，是否保留自己的名字仍由 bot 自己选择。

想固定“爱丽丝”，就在配置中将**基础名字**填写为 `爱丽丝`。此时 bot 只决定后缀，例如传入 `摸鱼中`，显示为 `爱丽丝 摸鱼中`；每次替换旧后缀，不会越叠越长。传入空字符串可清除后缀，只保留 `爱丽丝`。

## 管理面板

在 AstrBot 的插件管理中打开 **随心名片 → 视图 → 名片管理**。无需另开端口或填写 API Key；看不到“视图”入口时，请更新 AstrBot。

- **概览**：最近回读的名片、改名趋势和提醒状态。
- **群管理**：回读 QQ、手动改名、暂停或恢复日常提醒、安排下次聊天提醒。
- **改动记录**：查看前后名片与实际结果，按群、来源、日期筛选，导出 CSV 或 JSON。
- **配置与外观**：保存配置立即生效；可切换月白、夜航、玫瑰、森屿四套主题，支持手机访问。

记录从启用记录功能后开始，最多保留最近 1000 条，重载后仍保留。面板展示的是**最近一次回读结果**，需要查看 QQ 当前名片时点击“回读 QQ”。

## 配置

| 选项 | 默认 | 用途 |
| --- | --- | --- |
| 基础名字（可选） | 留空 | 填写后固定名字，只允许 bot 修改后缀；留空可自由修改完整名片 |
| 改名提醒间隔 | 30 分钟 | 0 关闭提醒，bot 仍能主动使用工具 |
| 两次改名的最短间隔 | 60 秒 | 控制改名频率，0 不限制 |
| 给 bot 的改名提醒 | 内置提醒 | 可调整语气或命名偏好 |
| 自动显示小世界串门状态 | 开启 | 与小世界配合，串门时显示拜访或接待状态，归家恢复原名片 |

名片应保持简短，**基础名字与后缀合计**最多 32 个字符且不超过 60 个 UTF-8 字节；中文和表情占用的字节更多。过长时会请 bot 缩短，不会擅自截断。基础名字配置本身不会立即改名，下一次成功使用工具才会生效。

修改后会回读确认。失败时暂停尝试 5 分钟，无法回读时明确告知未确认。重载后提醒与冷却重新计时，群暂停设置与改名记录会保留，QQ 上的名片也会保留。

后台搜索 **`[随心名片]`**，可看到提醒剩余时间、模型是否开始、是否调用工具，以及最后确认的名片。

## 与小世界一起生活

小世界会把日常群名片交给随心名片管理。开启 **自动显示小世界串门状态** 后，确认相见时显示如 `爱丽丝 拜访艾拉`，归家后恢复原先的名片。等待邀请接受时不会显示正在拜访。

请在小世界中开启对应会话和群名片同步，并让目标群收到一次实际消息。串门期间暂停日常改名提醒；手动让 bot 使用工具选择新名片时，会保存新选择，归家后显示。

要让小世界在自主发言时也能改名，请在其设置中开启**主动工具**，并在**全局允许工具**中加入 `set_free_group_card`。普通聊天的人格工具设置与小世界的自主工具白名单分别生效。
