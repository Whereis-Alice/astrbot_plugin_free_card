# 随心名片

让 bot 根据聊天、心情和人格，自由决定自己的 QQ 群名片。

插件定期在模型准备回复时给出提醒。bot 想换名字时调用工具，也可以保留原名。只修改机器人自己的群名片。

## 安装

1. 在 AstrBot 中通过 **OneBot v11 / aiocqhttp** 接入 QQ，如 LLOneBot、llbot 或 SnowLuma。
2. 在插件管理中从链接安装：

   ```text
   https://github.com/Whereis-Alice/astrbot_plugin_free_card
   ```

3. 在当前人格的工具设置中启用 **`set_free_group_card`**，使用支持工具调用的模型。
4. 关闭其他自动改名插件，再在群里与 bot 聊天。

**QQ 官方机器人不开放群名片修改接口，无法使用此功能。**

## 怎么用

默认每隔 30 分钟，在下一次群聊模型请求中提醒 bot 考虑换名。首次群聊会立即提醒，群里没人聊天时不会自行触发。

你也可以直接对它说：

> 按你现在的心情，给自己换个群名片。

> 把你的群名片改成“爱丽丝 摸鱼中”。

工具只接收一个参数 `card`。**基础名字留空**时，bot 自由决定完整名片。

想固定“爱丽丝”，就在配置中将**基础名字**填写为 `爱丽丝`。此时 bot 只决定后缀，例如传入 `摸鱼中`，显示为 `爱丽丝 摸鱼中`；每次替换旧后缀，不会越叠越长。传入空字符串可清除后缀，只保留 `爱丽丝`。

## 配置

| 选项 | 默认 | 用途 |
| --- | --- | --- |
| 基础名字（可选） | 留空 | 填写后固定名字，只允许 bot 修改后缀；留空可自由修改完整名片 |
| 改名提醒间隔 | 30 分钟 | 0 关闭提醒，bot 仍能主动使用工具 |
| 两次改名的最短间隔 | 60 秒 | 控制改名频率，0 不限制 |
| 给 bot 的改名提醒 | 内置提醒 | 可调整语气或命名偏好 |

名片应保持简短，**基础名字与后缀合计**最多 32 个字符且不超过 60 个 UTF-8 字节；中文和表情占用的字节更多。过长时会请 bot 缩短，不会擅自截断。基础名字配置本身不会立即改名，下一次成功使用工具才会生效。

修改后会回读确认。失败时暂停尝试 5 分钟，避免连续请求；仅收到接口接受、无法回读时会明确告知未确认。插件重载后提醒与冷却重新计时，QQ 上的名片会保留。
